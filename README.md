# raizes-do-nordeste-backend
API REST em camadas para a rede fictícia Raízes do Nordeste: pedidos multicanal (APP, TOTEM, BALCAO, PICKUP, WEB), estoque por unidade, pagamento mock idempotente, fidelidade com consentimento LGPD, promoções e auditoria. Projeto Multidisciplinar ADS 2026. Python/Flask, JWT, SQLite, OpenAPI.
